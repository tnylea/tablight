One more step: set the shortcut

Chrome couldn't assign ⌘⇧Space to the spotlight tab switcher automatically. That usually means another installed extension already uses that key. Chrome doesn't let extensions bind shortcuts themselves, so it takes a few seconds by hand:

  1. Click Open shortcut settings below.
  2. Find Tab Thumbnails & Spotlight → Toggle the tab spotlight switcher.
  3. Click the box and press ⌘⇧Space. Chrome will move it over from the other extension.
Waiting for the shortcut…

You're all set

⌘⇧Space now opens the spotlight tab switcher. Press it again, or Space, to bounce back to your previous tab. You can close this page.
